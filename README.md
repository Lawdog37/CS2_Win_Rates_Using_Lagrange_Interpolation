The goal of this project is to understand the critical impact points where a player's economy in Counter-Strike 2 crosses a 50 percent win rate, as well as gaining insight into round win percentage regardless of economic strength. This knowledge is ascertained by using numerical computation methods, more specifically, a hybrid Newton's/Secant method and Lagrange Interpolation. The data was collected from 20 personal Counter-Strike 2 games and then pulled from an API and cleaned. Lagrange Interpolation was then applied to the data set in order to calculate win percentages based on current economic values. The hybrid Newton's/Secant method was then used to find the minimum threshold where the win percentage crossed 50. The results supported the idea that a higher player economy led to a higher round win percentage. The hybrid method confirmed that the minimum threshold of a 50 percent win rate settled at $3700. This project shows that the worlds of competitive gaming and mathematics have a deeper connection than what is assumed at first sight.
